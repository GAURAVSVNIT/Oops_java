
## About this repository
Team project (2 contributors): a Java REST service wrapping the open-source [Program AB](https://code.google.com/archive/p/program-ab/) AIML engine (`org.alicebot.ab`, (c) ALICE A.I. Foundation, LGPL). The service layer is based on [deepsarda/Aeona-Aiml](https://github.com/deepsarda/Aeona-Aiml) (MIT, (c) 2022 deepsarda); see `LICENSE`.
